
# Proyecto Dashboard Fullstack

<p>
  
  Hola a todos este es un repositorio en el que trabajé mucho tiempo. Se trata de un **Dashboard Interactivo** utilizando tecnologías Fullstack: HTML, CSS y Vanilla     Javascript para el Frontend y Python FLask para el Backend. Tomando como punto de partida un archivo .CSV con cientos de registros por año de las Emisiones de Carbono por país y por region. Esta información fué filtrada y procesada utilizando la librería pandas en Python, para luego ser enviada al cliente a través de los distintos endpoints utilizando Flask.
</p>
